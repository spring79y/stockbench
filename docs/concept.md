# 증시 브리핑 — 제품 컨셉

## 한 줄 정의

대부분의 개미가 반드시 알아야 할 한·미 정보를 알기 쉽게 간추려 브리핑하고, 시나리오와 점검으로 의사결정에 도움을 주는 서비스.

## 확정 사항

| 항목 | 내용 |
|------|------|
| 이름 | 증시 브리핑 |
| 타깃 | 일반 개미 |
| 핵심 흐름 (한·미) | 시장 온도 → 바로 볼 지표 → 브리핑 → 시나리오 → 오늘 볼 것 |
| 핵심 흐름 (증시개요) | 시장 온도 → 환율·금리·유가 → 한눈 브리핑(한·미) → 일정 → 속보(1~3) |
| 시장 | 국내 + 미국 |
| 홈 구조 | 탭 3개 — 증시개요(한눈 요약 허브) / 한국 / 미국. **한·미만 동일 풀 흐름** |
| 상대 시장 | 단일 시장 탭에도 **접힌 보조 한 줄·한 블록**으로 남김 |
| 풀 브리핑 슬롯 | 한·미 장전·장중·장후 + **12:30 미국 점검** (슬롯 상한 7 · **평일 자동 최대 6창**). `us-mid`는 수동/복구만. 장중·점검은 관측 틀 갱신(개장·매매 예측 아님) |
| 갱신 스케줄 | 자동: `us-post·kr-pre 07:00` · `us-noon·kr-mid 12:30` · `kr-post 15:40` · `us-pre 21:50` KST (주말 스킵). `us-mid 02:00`는 수동 |
| 톤 | 매수/매도 추천 금지. 근거 기반 해설·시나리오·점검 |
| UI | 보기 쉽고 친숙한 보드. 개요는 시세·뉴스 모자이크 대시보드가 아님 |
| 업데이트 | 자동화. AI가 해석 생성, 숫자는 비AI 수집 |

| 항목 | 현재 | 톤 |
|------|------|-----|

Discuss 원칙: 사용자가 말한 “예측 지수”는 **기대·경계 신호**로 재프레이밍한다.

## 홈 탭

1. **증시개요** (기본) — **한눈 요약 허브**. 한·미 풀 흐름과 무관. 지수 + 환율·금리·유가 + 한·미 「오늘은 ○○」1줄·점검 ≤2(Decision 재사용) + 일정 + 시장 연결 속보 1~3. 바로 볼 지표·시나리오 A/B·오늘 볼 것(전체)·풀 브리핑 복제 없음 — 풀은 한국/미국 탭.
2. **한국** — 국내 중심 브리핑·시나리오·오늘 볼 것(최대 5) + 미국은 접힌 보조
3. **미국** — 미장 중심 + 한국은 접힌 보조

### 탭 UX 원칙

- **차용:** 코스피랩식 **상단 세그먼트/탭 조작감**만 (친숙한 시장 전환)
- **비차용:** 시세·뉴스·리포트를 한 화면에 깔아 두는 대시보드 레이아웃 복제
- **한·미 1순위:** 브리핑 흐름 (온도 → 참고 스캔 → 브리핑 → 시나리오 → 오늘 볼 것)
- **개요 1순위:** 현재 분위기·필수 맥락을 짧게. 속보는 시장 영향이 분명한 헤드라인만

## 갱신 슬롯

### 풀 브리핑 (시나리오·점검 포함 · 한·미 장전·장중·장후)

| 슬롯 | 시점 (대략) | 초점 |
|------|-------------|------|
| 한국 장전 | ~07:00 KST | 전 거래일 국내 요약 + 오늘 국내 관측 틀·신호 (미국 오버나잇은 조건부 브릿지) |
| 한국 장중 | ~12:30 KST | 오전 소화 + 오후 관측 틀·시나리오·점검 갱신 (매매 신호·개장 예측 금지) |
| 미국 점검 | ~12:30 KST | 미 장후~장전 공백 점검 · 직전 미 세션·오버나잇 + 저녁 장전 관측 틀 (`us-noon`, 한국 장중과 연속 실행) |
| 한국 장후 | ~15:40 KST | 오늘 국내 세션 결과·수급·시총·주요 촉발 요인 리캡 + 밤 미장 점검 |
| 미국 장전 | ~21:50 KST | 전 거래일 미국 요약 + 오늘 미국 관측 틀·신호 (국내 마감은 조건부 브릿지) |
| 미국 장중 | 수동 (`us-mid`) | 미 장중 관측 틀·시나리오·점검 갱신 (자동 cron 없음 · 매매 신호·방향 예측 금지) |
| 미국 장후 | ~07:00 KST | 오늘 미국 세션 결과·메가캡·주요 촉발 요인 리캡 + 다음 국내 장전 연결 |

장중·점검 풀은 **관측 틀 갱신**이다. 연속·실시간 발행이나 장중 매매 시그널형 풀은 하지 않는다. `us-noon`(12:30)은 미 정규장 중이 아니며, 미국 탭의 장후~장전 공백을 메운다.

## 콘텐츠 파이프라인

```text
풀: Collector → Briefing → Decision → Guard → Publisher
```

| 단계 | 역할 |
|------|------|
| Collector | Yahoo·네이버 등 API로 지수·매크로·시총·수급·실적 숫자·`contextNews` 수집 → **Evidence Pack** 구조화 (비AI). **사실·플래그만** — EventList `oneLiner`에 판정 보류/호재·악재 등 해석 카피 금지 |
| Briefing | Evidence Pack → 헤드라인·불릿·근거 (**탭별**, LLM). **발행 본문(유저 불릿) = LLM.** Guard soft 거절 소진 시 **마지막 LLM 드래프트 발행**(스탬프 갱신). **하드 블록**(추천·결과 창작·사실 불일치 등)·LLM 실패 시만 **직전 유지**. seed/thin은 콜드스타트·ops 사실 앵커만 (보드 본문 아님 · 「후보다/가늠하는 때다」·「반응 근거 부족」금지). 실적 **결과+시장 반응** 서술은 Briefing(LLM) 전담. 뉴스 없으면 반응 생략. **한·미는 해당 시장 1순위·상대 시장 ≤1불릿 브릿지** |
| Decision | 브리핑+Evidence Pack → 시나리오 A/B + 「오늘 볼 것」3~5 (**탭별**, LLM). 해석은 Evidence 사실 기반 · beatLabel/뉴스 없는 극성·가이던스 단정 금지. UI 「오늘 볼 것/점검」라벨 ≠ seed template voice |
| Guard | 추천/예측 톤·숫자 복창·공허·**시점 둔갑**·사실 불일치·**due+Evidence 누락·재평가 없는 키워드만**·**결과 창작**·**beat 극성 반전**·**뉴스 없는 가이던스 단정**·**숫자+뉴스인데 가이던스/반응 누락**·**슬롯 톤 불일치** 차단. 숫자+뉴스면 이중 서술 허용·필수. 거절 사유→`findingsToRepairHints`(**프롬프트 채널만** — 유저 불릿에 수정 지시문 패치 금지). **최대 3회**. soft만 남은 최종 거절 → **마지막 LLM 드래프트 발행**. 하드 블록·LLM 실패 → **같은 시장 직전 좋은 본문 유지**. facts-only는 콜드스타트/ops용이며 **유저 보드 「오늘의 브리핑」본문으로 쓰지 않음**. 「반응 근거 부족」등 메타는 발행 본문 금지 |
| Publisher | `src/data/published/latest.json` (version 2, views.all/kr/us). **published briefing ≠ internal seed voice** |

### Evidence Pack (LLM 입력)

Briefing/Decision이 받는 구조화 근거. UI 대시보드가 아님.

| 섹션 | 내용 |
|------|------|
| 세션 | 슬롯·초점·수집시각 |
| 시장 온도 | 한·미 평균, 디커플링 갭 · 장전은 전일세션 평균도 제공 |
| 지수·매크로 | **전일세션마감 vs 현재(장중/프리)** 분리. 복창 금지, evidenceIds 후보 |
| 수급 | 전 거래일 수급(장전 요약용) + 수집 기준일 + 5거래일 합 |
| 시총 상위 | 평균·분산(고−저)·상승/하락 수 |
| 기대·경계 신호 | KS200·VIX 등 |
| 일정 | 경제 캘린더 + **시총·섹터 브릿지 실적**(Yahoo 발표일·시장 예상 매출·주당순이익(EPS)·**선택적 영업이익(네이버 금융, 분기 매칭 시)**·발표 직후 `finance/quarter` 지연 시 **네이버 공정공시 잠정실적(연결) 매출·영업이익 실제**·선택적 beatLabel·`contextNews`). UI는 쉬운 라벨·매출(+영업이익) 우선·EPS 보조. EventList oneLiner는 최소 사실+단위만 · 숫자는 비AI·창작 금지 |
| 리스크·지정학 | 유가·VIX·환율 플래그 + Yahoo 지정학 헤드라인(숫자 연결 시에만). 정치 뉴스 올인원 아님 |
| 직전 발행 | 이전 헤드라인(반복 방지) + **같은 시장 탭 직전 1건**의 구조화 연속성 |
| 직전 연속성 | `scenarios` A/B 한 줄 · `checkItems` · 미결 `upcoming`. Collector가 due를 Evidence 사실로 해석(`carryForward`/`dueFollowUps`). **forceCite는 재평가 문장 필수**(키워드만 금지). 무관 due 드롭. 본문 덤프·멀티데이 스택 금지. 최대 5 · forceCite ≤3 · 무변화 2슬롯 드롭 |

LLM: `.env.local` / Actions — 운영은 **Google Gemini 무료**(기본 `gemini-3.5-flash-lite`). 숫자는 비AI. 한도·품질 미달·하드 블록이면 직전 본문 유지. 슬롯 LLM **503·timeout**은 30초 간격·최대 12분 재시도 후 직전 유지. 소형 로컬은 비권장.  
실행: `npm run pipeline -- kr-post` (슬롯: kr-pre / kr-mid / kr-post / us-pre / us-mid / us-noon / us-post)  
스케줄: 자동 `us-post·kr-pre 07:00` · `us-noon·kr-mid 12:30` · `kr-post 15:40` · `us-pre 21:50` (주말 스킵). `us-mid`는 수동/`all`. 탭: 한국슬롯→통합+한국, 미국슬롯→통합+미국. 웹 푸시는 KST 00:00–07:00 미발송이며, **latest.json 커밋·프로덕션 반영 후**에만 발송.  
실패·키 없음 → seed는 **사실 앵커/개발·콜드스타트용**일 뿐 full 발행 보드 본문에 넣지 않음. **Guard block 시 scope당 최대 3회 재생성. soft만 남은 최종 거절 → 마지막 LLM 드래프트 발행. 하드 블록·LLM 실패면 같은 시장 직전 본문 유지.** 뉴스 없는 반응은 **생략**(「반응 근거 부족」금지).

다가오는 일정: KST **D-day ~ D-day+1** 유지(발표 다음날 결과 확인), **D-day+2**부터 삭제. 발표 후에는 결과 라인(`eventResultComment` · FRED 숫자 또는 집계 대기) 표시.

### 하지 않는 시점 오류

- 장중·프리 등락을 「전일 마감」으로 표기
- Evidence에 없는 전일 수치 창작
- 장전 브리핑을 개장 방향 예측으로 쓰는 것

홈 UI: 상단 세그먼트(증시개요/한국/미국) + 한·미는 세션 힌트 + 접힌 상대 시장. 백그라운드 복귀 시 홈은 항상 hard reload(신선도 게이트 없음).

Cursor 에이전트: `.cursor/agents/briefing.md`, `decision.md`, `guard.md` (+ `discuss.md`)

## 하지 않는 것

- 종목 매수/매도 추천
- TradingView급 풀 차트 툴 (초기)
- 시세 나열이 목적인 올인원 포털화
- 근거 없는 단정·예측 단언 / “향후 주가 예측 지수” 포지셔닝
- 장중 연속·시그널형 풀 / 실시간 반복 발행
- 한국/미국을 별도 사이트·별도 IA로 쪼개는 것 (탭으로만 구분)
- 코스피랩형 시세·뉴스·리포트 모자이크 대시보드 복제
- 개요 탭의 정치·전쟁 올인원 속보 피드
