# 증시 브리핑 — 제품 컨셉

## 한 줄 정의

대부분의 개미가 반드시 알아야 할 한·미 정보를 알기 쉽게 간추려 브리핑하고, 시나리오와 점검으로 의사결정에 도움을 주는 서비스.

## 확정 사항

| 항목 | 내용 |
|------|------|
| 이름 | 증시 브리핑 |
| 타깃 | 일반 개미 |
| 핵심 흐름 (한·미) | 시장 온도 → 바로 볼 지표 → 브리핑 → 시나리오 → 오늘 볼 것 |
| 핵심 흐름 (증시개요) | 시장 온도 → 환율·금리·유가 → 한눈 브리핑(한·미) → 일정 → 속보(1~3) |
| 시장 | 국내 + 미국 |
| 홈 구조 | 탭 3개 — 증시개요(한눈 요약 허브) / 한국 / 미국. **한·미만 동일 풀 흐름** |
| 상대 시장 | 단일 시장 탭에도 **접힌 보조 한 줄·한 블록**으로 남김 |
| 풀 브리핑 슬롯 | 한·미 장전·장중·장후 + **12:30 미국 점검** (**최대 7회/일**). 장중·점검은 관측 틀 갱신(개장·매매 예측 아님) |
| 갱신 스케줄 | 풀: `us-post·kr-pre 07:00` · `us-noon·kr-mid 12:30` · `kr-post 15:40` · `us-pre 21:50` · `us-mid 02:00` KST (주말 스킵) |
| 톤 | 매수/매도 추천 금지. 근거 기반 해설·시나리오·점검 |
| UI | 보기 쉽고 친숙한 보드. 개요는 시세·뉴스 모자이크 대시보드가 아님 |
| 업데이트 | 자동화. AI가 해석 생성, 숫자는 비AI 수집 |

## 바로 볼 지표 (예측 아님 · 한국/미국 탭)

| 항목 | 현재 | 톤 |
|------|------|-----|
| 수급 분석 | 네이버 금융 일자별 시장 합계 (코스피·코스닥) **최근 1주** | 일별·장후 집계. 미국 탭에서는 숨김 |
| 코스피200야간선물 | 공개 JSON (`yagan` nightfutures) · **한국 탭만** · 약 1분 폴링 | 야간 온도 참고 · 주문/매매 판단·예측 아님 |
| KS200−코스피 갭 | Yahoo 현물 `^KS200` (신호만, UI 카드 없음) | 야간선물과 별개 · 대형주 온도 참고 |
| 시가총액 상위 5 | Yahoo marketCap 정렬 · 보조 차트 · KR 수급동향 · 펼침 탭 「관련 헤드라인」(종목당 1~2, lazy) | 순위판·종목 피드 아님. 지수·시총5 온도 맥락 |
| 기대·경계 신호 | KS200−코스피 갭, VIX, 시총5 평균 | “향후 주가 예측”이 아니라 온도·흔들림 점검 |
| 한·미 탭 차트 | 테이블 지수 보조 라인차트 1개 (탭 전환) · 1일=당일 정규장 · ≤1분 폴링 | TradingView급 툴·시세 포털화 금지 |

Discuss 원칙: 사용자가 말한 “예측 지수”는 **기대·경계 신호**로 재프레이밍한다.

## 홈 탭

1. **증시개요** (기본) — **한눈 요약 허브**. 한·미 풀 흐름과 무관. 지수 + 환율·금리·유가 + 한·미 짧은 브리핑 + 일정 + 시장 연결 속보 1~3. 바로 볼 지표·시나리오·오늘 볼 것 없음.
2. **한국** — 국내 중심 브리핑·시나리오·오늘 볼 것(최대 5) + 미국은 접힌 보조
3. **미국** — 미장 중심 + 한국은 접힌 보조

### 탭 UX 원칙

- **차용:** 코스피랩식 **상단 세그먼트/탭 조작감**만 (친숙한 시장 전환)
- **비차용:** 시세·뉴스·리포트를 한 화면에 깔아 두는 대시보드 레이아웃 복제
- **한·미 1순위:** 브리핑 흐름 (온도 → 참고 스캔 → 브리핑 → 시나리오 → 오늘 볼 것)
- **개요 1순위:** 현재 분위기·필수 맥락을 짧게. 속보는 시장 영향이 분명한 헤드라인만

## 갱신 슬롯

### 풀 브리핑 (시나리오·점검 포함 · 한·미 장전·장중·장후)

| 슬롯 | 시점 (대략) | 초점 |
|------|-------------|------|
| 한국 장전 | ~07:00 KST | 전 거래일 국내 요약 + 오늘 국내 관측 틀·신호 (미국 오버나잇은 조건부 브릿지) |
| 한국 장중 | ~12:30 KST | 오전 소화 + 오후 관측 틀·시나리오·점검 갱신 (매매 신호·개장 예측 금지) |
| 미국 점검 | ~12:30 KST | 미 장후~장전 공백 점검 · 직전 미 세션·오버나잇 + 저녁 장전 관측 틀 (`us-noon`, 한국 장중과 연속 실행) |
| 한국 장후 | ~15:40 KST | 오늘 국내 세션 결과·수급·시총·주요 촉발 요인 리캡 + 밤 미장 점검 |
| 미국 장전 | ~21:50 KST | 전 거래일 미국 요약 + 오늘 미국 관측 틀·신호 (국내 마감은 조건부 브릿지) |
| 미국 장중 | ~02:00 KST | 미 장중 관측 틀·시나리오·점검 갱신 (매매 신호·방향 예측 금지) |
| 미국 장후 | ~07:00 KST | 오늘 미국 세션 결과·메가캡·주요 촉발 요인 리캡 + 다음 국내 장전 연결 |

장중·점검 풀은 **관측 틀 갱신**이다. 연속·실시간 발행이나 장중 매매 시그널형 풀은 하지 않는다. `us-noon`(12:30)은 미 정규장 중이 아니며, 미국 탭의 장후~장전 공백을 메운다.

## 콘텐츠 파이프라인

```text
풀: Collector → Briefing → Decision → Guard → Publisher
```

| 단계 | 역할 |
|------|------|
| Collector | Yahoo·네이버 등 API로 지수·매크로·시총·수급 수집 → **Evidence Pack** 구조화 (비AI) |
| Briefing | Evidence Pack 섹션 입력 → 헤드라인·불릿·근거 (**탭별**, LLM → seed). **한·미는 해당 시장 1순위·상대 시장 ≤1불릿 브릿지**. 숫자 복창·공허 일반론 금지. **직전 연속성은 체크리스트**(라이브 사실 우선 · 현재 숫자로 재평가) |
| Decision | 브리핑+Evidence Pack → 시나리오 A/B + 「오늘 볼 것」3~5 (**탭별**, LLM → seed). 직전 A/B·점검을 복창하지 않고 갱신 |
| Guard | 추천/예측 톤·숫자 복창·공허·**시점 둔갑(전일↔장중)**·사실 불일치·**due+Evidence 연속성 누락**·**결과 창작** 차단. 최대 5회 재생성. 전부 거절 시 **직전 발행 유지** |
| Publisher | `src/data/published/latest.json` (version 2, views.all/kr/us) |

### Evidence Pack (LLM 입력)

Briefing/Decision이 받는 구조화 근거. UI 대시보드가 아님.

| 섹션 | 내용 |
|------|------|
| 세션 | 슬롯·초점·수집시각 |
| 시장 온도 | 한·미 평균, 디커플링 갭 · 장전은 전일세션 평균도 제공 |
| 지수·매크로 | **전일세션마감 vs 현재(장중/프리)** 분리. 복창 금지, evidenceIds 후보 |
| 수급 | 전 거래일 수급(장전 요약용) + 수집 기준일 + 5거래일 합 |
| 시총 상위 | 평균·분산(고−저)·상승/하락 수 |
| 기대·경계 신호 | KS200·VIX 등 |
| 일정 | 경제 캘린더 + **시총·섹터 브릿지 실적**(Yahoo 발표일·컨센서스 참고) |
| 리스크·지정학 | 유가·VIX·환율 플래그 + Yahoo 지정학 헤드라인(숫자 연결 시에만). 정치 뉴스 올인원 아님 |
| 직전 발행 | 이전 헤드라인(반복 방지) + **같은 시장 탭 직전 1건**의 구조화 연속성 |
| 직전 연속성 | `scenarios` A/B 한 줄 · `checkItems` · 미결 `upcoming`. Collector가 due를 Evidence 사실로 해석(`carryForward`/`dueFollowUps`). 본문 덤프·멀티데이 스택 금지. 최대 5 · forceCite ≤3 · 무변화 2슬롯 드롭 |

LLM: `.env.local` — 품질 우선 시 Anthropic/OpenAI 권장. Ollama는 가능하나 소형 모델은 비권장.  
실행: `npm run pipeline -- kr-post` (슬롯: kr-pre / kr-mid / kr-post / us-pre / us-mid / us-noon / us-post)  
스케줄: 풀 `us-post·kr-pre 07:00` · `us-noon·kr-mid 12:30` · `kr-post 15:40` · `us-pre 21:50` · `us-mid 02:00` (주말 스킵). 탭: 한국슬롯→통합+한국, 미국슬롯→통합+미국. 웹 푸시는 KST 00:00–07:00 미발송이며, **latest.json 커밋·프로덕션 반영 후**에만 발송.  
실패·키 없음 → seed fallback. **Guard block 시 scope당 최대 5회 재생성. 전부 거절이면 latest를 덮지 않고 직전 발행 유지.**

### 하지 않는 시점 오류

- 장중·프리 등락을 「전일 마감」으로 표기
- Evidence에 없는 전일 수치 창작
- 장전 브리핑을 개장 방향 예측으로 쓰는 것

홈 UI: 상단 세그먼트(증시개요/한국/미국) + 한·미는 세션 힌트 + 접힌 상대 시장

Cursor 에이전트: `.cursor/agents/briefing.md`, `decision.md`, `guard.md` (+ `discuss.md`)

## 하지 않는 것

- 종목 매수/매도 추천
- TradingView급 풀 차트 툴 (초기)
- 시세 나열이 목적인 올인원 포털화
- 근거 없는 단정·예측 단언 / “향후 주가 예측 지수” 포지셔닝
- 장중 연속·시그널형 풀 / 실시간 반복 발행
- 한국/미국을 별도 사이트·별도 IA로 쪼개는 것 (탭으로만 구분)
- 코스피랩형 시세·뉴스·리포트 모자이크 대시보드 복제
- 개요 탭의 정치·전쟁 올인원 속보 피드
